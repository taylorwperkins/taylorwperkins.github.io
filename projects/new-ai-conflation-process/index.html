WHY THIS PROJECT MATTERS

Exploring More Scalable Utility Conflation Workflows

Utility organizations often maintain large spatial datasets that must be updated and reconciled as infrastructure changes over time. Traditional conflation approaches can require extensive field data collection using technologies such as GPS, LiDAR, or drone surveys, increasing project cost, scheduling requirements, and resource demands.

This project explored an alternative AI-based GIS workflow that leveraged publicly available aerial imagery together with geospatial analysis techniques to investigate a more scalable approach for feature extraction and conflation. Rather than relying on a dedicated pre-planned field collection effort, the workflow evaluated how existing publicly available imagery could support the creation of updated utility feature datasets.

My work focused on supporting the evaluation of this workflow through feature dataset creation, analysis, documentation, and assessment of the operational advantages offered by an AI-based approach.
