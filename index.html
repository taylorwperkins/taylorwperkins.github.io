FEATURED PROJECT

New AI Conflation Process

Professional Consulting Project (2025)

This project explored a new AI-based approach for improving utility and infrastructure data conflation by leveraging publicly available aerial imagery together with modern GIS capabilities. The objective was to investigate a workflow that could reduce traditional pre-planning requirements while supporting scalable, efficient spatial data collection.

Problem

Traditional conflation workflows often require extensive planning, manual data collection, higher project costs, and increased opportunities for human error.

My Contributions

  • Creating feature datasets for evaluating an AI-based conflation process.
  • Studying publicly available aerial imagery sources suitable for utility mapping.
  • Evaluating advantages of AI-based approaches compared with traditional conflation methods.
  • Producing technical documentation explaining business applications and technical concepts.

Technologies

ArcGIS Pro Artificial Intelligence Aerial Imagery Utility GIS Open Government Data Spatial Analysis

Outcome

Helped evaluate an AI-based approach that reduced dependence on traditional pre-planning activities while demonstrating how publicly available aerial imagery could support more scalable utility and infrastructure data workflows.

FEATURED PROJECT

Cartographic Information Model Spreadsheet Script

Professional Consulting Project (2026)

This project took advantage of Python scripting functionality available in ArcGIS to create an automated process that can collect CIM-related data properties of individual ArcGIS projects and display them in an external Excel spreadsheet.

Problem

Esri's Cartographic Information Model contains many styling and design-related properties for different ArcGIS projects. It would take much time, resources, and overall effort to collect, organize, and show this data manually and correctly.

My Contributions

  • Spearheading a Python script to collect and extract CIM project data automatically.
  • Handling the organization and schema of the Excel spreadsheet with the CIM project data.
  • Studying the CIM and the value of its styling and design-related properties.
  • Producing technical documentation explaining this tool and it's purpose to users and further developers.

Technologies

ArcGIS Pro ArcGIS Online Python Excel Esri's Cartographic Information Model Artificial Intelligence Data Automation

Outcome

Produced a Python script that eschewed manual data collection and organization in favor of an automated and dynamic process for displaying CIM-related data properties, thus saving significant time, resources, and reducing error potential.
